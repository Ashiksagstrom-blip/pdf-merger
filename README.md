# 📄 Local PDF Merger

A free, privacy-first PDF merger that runs **100% in your browser**. Your files never leave your device.

 **[Try it live](https://ashiksagstrom-blip.github.io/pdf-merger/)**

## ✨ Features

- **100% Private** – Files are processed locally using WebAssembly. Nothing is uploaded to any server.
- **No signup required** – Just open the page and start merging.
- **No watermarks** – Get clean, professional PDFs every time.
- **Drag & drop** – Easily reorder files before merging.
- **Works offline** – Once loaded, no internet connection needed.
- **Free forever** – No hidden costs, no premium tier.

## 🔒 How it works

This tool uses [pdf-lib](https://pdf-lib.js.org/) to manipulate PDF files directly in your browser via JavaScript. The merging happens on your device's CPU – no server is involved at any point.

## 🚀 How to use

1. Open the [live site](https://ashiksagstrom-blip.github.io/pdf-merger/)
2. Drag and drop your PDF files (or click to select)
3. Drag files to reorder them
4. Click "Merge and download"
5. Done! Your merged PDF is saved to your device

##  Running locally

You can also run this tool locally without any server:

1. Clone this repository
2. Open `index.html` in any modern browser
3. That's it!
